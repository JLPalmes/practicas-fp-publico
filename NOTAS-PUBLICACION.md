Prácticas FP se distribuye como software libre bajo GNU AGPLv3 exclusivamente.

- **Mac 1.8.4:** Apple Silicon, macOS 14 o posterior. Abre el DMG y arrastra la aplicación a Aplicaciones. Firma local, sin notarización.
- **Windows 1.8.4-windows.3:** edición de pruebas para Windows 10/11 de 64 bits. Ejecuta el instalador. .NET Framework 4.8 recomendado. Sin certificado de firma digital.

Windows se compila desde esta etiqueta y se publica tras superar las pruebas
funcionales y de interfaz. Mac reutiliza su instalador 1.8.4 verificado, tras
comprobar que sus fuentes permanecen idénticas y verificar su suma SHA-256. Se adjuntan la licencia, el aviso y
SHA256SUMS.txt. El código fuente correspondiente está disponible en los archivos
Source code de esta publicación, incluidos los procedimientos de compilación.

Los datos permanecen en cada equipo. Conserva una copia antes de actualizar o
trasladar datos entre sistemas. No existe sincronización ni fusión automática;
el intercambio completo de ida y vuelta entre Mac y Windows sigue pendiente de
verificación. Revisa las guías del repositorio antes de usar datos reales.

Mac 1.8.3 reduce márgenes y anchos mínimos, adapta los hitos en filas numeradas y permite desplegar las secciones pulsando toda su cabecera.

Mac 1.8.4 mantiene la ficha siempre junto al panel en Alumnas, Empresas y Tutores. La lista de tutores muestra sus empresas y alumnas, incluidas las de periodos posteriores sin duplicados. El menú Informe conserva una opción explícita de curso completo.

Windows 1.8.4-windows.3 incorpora las fichas permanentes con selección automática,
la lista de tutores con empresa y alumnas de todos los periodos, una distribución
más compacta, hitos en filas y cabeceras completas pulsables. Incluye pruebas de
formularios reales y vistas previas generadas con datos ficticios. Sigue pendiente
la comprobación manual en un equipo Windows del usuario.
