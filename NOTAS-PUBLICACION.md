# Prácticas FP 2.1.11 para Windows

La búsqueda de actualizaciones se ejecuta en cada arranque y completa el autoguardado antes de instalar. Se incorporan los avisos de autoría actualizados del Mac.

La aplicación se denomina Prácticas FP. La edición actual es la única que se mantiene para Windows.

Alumnas, Empresas y Tutores guardan automáticamente al editar y al navegar, sin botones ni mensajes rutinarios de guardado. El guardado conserva el foco y los campos de edición.
Los periodos usan una sola fecha de cierre. Las horas del periodo cerrado reflejan
las cumplidas, y el siguiente periodo recibe las que faltan para completar el
objetivo general, descontando las horas de cursos anteriores.

Requiere Windows 10 u 11 x64 y Microsoft Edge WebView2. Los datos de las instalaciones
anteriores se recuperan desde la misma carpeta. Se adjuntan el instalador y sus fuentes.
El catálogo de actualizaciones Windows ofrece la versión firmada 2.1.10. Para anunciar esta versión 2.1.11 queda pendiente firmar su instalador con la clave custodiada en el Mac.
